# Общие контракты клиента

В папке находится копия общего протокола `protocol.js`: типы сообщений, коды ошибок, перечисления и константы, которые использует Electron-клиент.

**Канонический источник — `server/shared/protocol.js`.** Копию в этой папке нельзя редактировать вручную: изменения разойдутся с сервером.

Синхронизация и проверка:

```powershell
cd server
npm run shared:sync
npm run shared:check
```

Проверка из клиента:

```powershell
cd app
npm run shared:check
```

Скрипты сравнивают SHA-256 файлов. Если папка второй части отсутствует, проверка пропускается — клиент и сервер можно устанавливать независимо.
