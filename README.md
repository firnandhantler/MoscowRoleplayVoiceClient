# MoscowRoleplay Voice — Windows-клиент

Клиент голосовой системы MoscowRoleplay для Roblox ER:LC: голос по близости,
радиоканалы, вход через Discord и привязка Roblox-аккаунта.

В этом репозитории находится **только клиент**. Серверная часть, PostgreSQL и
mediasoup развёрнуты отдельно и в этот репозиторий не входят.

## Возможности

- вход через Discord в системном браузере с возвратом сессии в приложение;
- голос по близости через mediasoup-client и WebRTC;
- радиоканалы, доступ к которым проверяет сервер по ролям Discord;
- Push-to-Talk и настройка клавиш радио и proximity без глобального перехвата;
- выбор устройств ввода и вывода, усиление микрофона, шумоподавление;
- низкая задержка голоса: минимальный джиттер-буфер, Opus 10 мс, без
  троттлинга фонового окна;
- безопасный renderer: `contextIsolation`, `sandbox`, без доступа к Node.js.

## Установка

Готовый установщик лежит в разделе **Releases**:

`MoscowRoleplay-Voice-Setup-0.6.2.exe`

После установки приложение возьмёт адрес сервера из `client-config.json`
в папке ресурсов. Если нужно сменить сервер, создайте
`%APPDATA%\MoscowRoleplay Voice\client-config.json`:

```json
{
  "serverUrl": "https://voice.example.com",
  "wsPath": "/ws"
}
```

## Сборка из исходников

Требования: Node.js 22.12 или новее, npm 11, Windows 10 или новее.

```powershell
npm install
npm run check
npm start
```

Сборка установщика:

```powershell
npm run dist
```

Результат появится в `release/` (в Git не попадает).

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd`.

## Структура

```text
electron/     главный процесс, preload, авторизация, WebSocket, настройки
renderer/     интерфейс, mediasoup-client, Web Audio, proximity и radio
shared/       копия общего протокола с сервером
docs/         документация по разработке клиента
scripts/      проверка синтаксиса, иконка, синхронизация протокола
```

Подробности: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Безопасность

- токен сессии хранится только в главном процессе и не передаётся в renderer;
- вход идёт в системном браузере, в URL передаётся только одноразовый код;
- клиент не хранит пароли Discord и не получает токены Discord;
- все права, расстояния и занятость радиоканалов проверяет сервер.

## Статус

Исходный код клиента публикуется для распространения приложения; серверная часть
остаётся приватной. Лицензия не определена. Не распространяйте код и конфигурацию
без разрешения владельца MoscowRoleplay.
