Подключение к голосу MoscowRoleplay

Вход выполняется через Discord. Сервер проверит вашу учётную запись, найдёт привязку Roblox через ER:LC Россия и подключит клиент к голосовой системе игрового сервера ER:LC.

  1. Откроется браузер по умолчанию со страницей входа Discord.
  2. После входа вернитесь в приложение — оно завершит подключение само.
  3. Проверка привязки Roblox на сервере и канал голоса по близости.

Клиент не хранит пароли и не получает токены Discord. Если браузер не открылся, проверьте настройки браузера по умолчанию.
