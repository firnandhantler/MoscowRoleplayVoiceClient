# Ресурсы клиента

В папке хранятся иконки Electron-клиента:

- `icon.ico` — иконка Windows-приложения и установщика;
- `icon.png` — иконка окна и исходник для генерации.

`icon.ico` и `icon.png` создаются скриптом `app/scripts/generate-icon.js` командой `npm.cmd run icon`. Бинарные ресурсы можно коммитить: секретов и пользовательских данных здесь нет.

Не добавляйте сюда токены, пароли и пользовательские файлы.
